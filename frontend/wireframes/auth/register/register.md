# Register Patient Wireframe

## Page Objective
Allow a patient to create an account and access the medical appointment platform.

## Main Sections

### Header
- Medibook Logo
- Application title
- Short subtitle

### Registration Form
Fields:
- Full Name
- Email Address
- Phone Number
- Date of Birth
- Password
- Confirm Password
- Terms and Conditions Checkbox

### Buttons
- Create Account
- Login Redirect Link


## UI Components
- Rounded inputs
- Light gray background
- Primary blue action button
- Responsive centered card

## Expected Actions
- Create patient account
- Redirect to login page
- Validate form fields

## Main Sections

### Header
- Medibook Logo
- Professional account title

### Account Type Selector
- Doctor
- Clinic

### Registration Form
Fields:
- Full Name
- Medical Specialty
- Professional Email
- Phone Number
- Password
- Confirm Password
- Terms Acceptance

### Buttons
- Create Professional Account
- Login Link

## UI Components
- Card layout
- Blue primary actions
- Professional clean interface
- Two-column layout on desktop

- Create doctor profile
- Register clinic account
- Validate medical information
