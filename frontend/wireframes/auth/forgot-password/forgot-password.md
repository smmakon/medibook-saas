# Forgot Password Wireframe

## Page Objective

Allow users to request a password reset link using their registered email address.

---

## Main Sections

### Header

- Medibook Logo
- Page title
- Short instruction text

---

### Forgot Password Form

#### Fields

- Email Address

---

### Buttons and Links

- Send Reset Link Button
- Back to Login Link

---

## UI Components

- Centered card layout
- Email input with icon
- Primary blue action button
- Informational message area
- Light background

---

## Expected Actions

- User enters email address
- System validates email format
- System sends password reset link if email exists
- Confirmation message is displayed

---

## Validation Rules

- Email is required
- Email must be valid
- Do not reveal whether the email exists for security reasons

---

## Success Message

```text
If an account exists with this email, a reset link has been sent.
````
