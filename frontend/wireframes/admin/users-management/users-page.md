# User Management Wireframe

## Page Objective
Allow administrators to manage all platform users.

## Sidebar Navigation
- Dashboard
- Users
- Doctors
- Patients
- Appointments
- Settings

## Main Features
### Search Bar
- Search user by name or email

### User Table
Columns:
- Name
- Email
- Role
- Status
- Actions

## Available Roles
- Admin
- Doctor
- Patient

## User Actions
- Edit User
- Delete User
- Suspend User
- Activate User

## Expected Actions
- Manage user accounts
- Assign permissions
- Monitor user activity
