# Profile Page Wireframe

## Page Objective
Allow users to manage their personal profile.

## Sidebar Navigation
- Dashboard
- Appointments
- History
- Profile
- Logout

## Profile Information
Fields:
- Full Name
- Email Address
- Phone Number
- Address
- Date of Birth
- Password Update

## Profile Picture
- Upload image button
- Preview avatar

## Buttons
- Save Changes
- Change Password

## Expected Actions
- Update profile information
- Upload profile image
- Change account password
