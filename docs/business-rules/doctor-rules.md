# Doctor Rules

## BR-DOC-01 — Availability Management
Doctor may configure:
- schedules
- breaks
- vacation
- working days

## BR-DOC-02 — Availability Deactivation
Unavailable doctor cannot receive appointments.

## BR-DOC-03 — Patient Access
Doctor accesses only assigned patients.

## BR-DOC-04 — Dashboard Access
Doctor dashboard displays:
- appointments
- availability
- assigned patients
