# Patient Rules

## BR-PAT-01 — Profile Isolation
Patient accesses only own data.

## BR-PAT-02 — Appointment Cancellation
Patient may cancel only own appointments.

## BR-PAT-03 — Cancellation Restriction
Cancellation denied:
- less than 2h before appointment
- completed appointment

## BR-PAT-04 — Dashboard Access
Patient dashboard displays:
- own appointments
- history
- profile
