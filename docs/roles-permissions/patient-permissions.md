# PATIENT Permissions — Medibook SaaS

# Overview

Patients can:
- manage their own appointments,
- manage their personal profile,
- access their appointment history.

Patients cannot access administrative resources.

---

# Appointment Permissions

| Action | Permission |
|---|---|
| Create appointment | ✅ |
| View own appointments | ✅ |
| Cancel own appointments | ✅ |
| Reschedule own appointments | ✅ |
| View appointment history | ✅ |

---

# Profile Permissions

| Action | Permission |
|---|---|
| View own profile | ✅ |
| Update own profile | ✅ |

# Dashboard Permissions

| Action | Permission |
|---|---|
| Access patient dashboard | ✅ |
| View upcoming appointments | ✅ |
| View appointment history | ✅ |

# Restrictions

| Restriction | Status |
|---|---|
| Access other patient data | ❌ |
| Access admin dashboard | ❌ |
| View all appointments | ❌ |
| Manage doctor schedules | ❌ |
| Access audit logs | ❌ |
| Access system settings | ❌ |
| Delete appointments globally | ❌ |

---

# Ownership Rules

Patients may only:
- access their own data,
- modify their own appointments,
- manage their own profile.
